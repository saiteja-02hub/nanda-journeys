# Nanda Tours & Travels 

## Build

- Create a polished one-page travel and chauffeur website with sticky desktop navigation, a one-hand mobile menu, and a persistent mobile call/WhatsApp/booking bar.
- Build the requested sections in order: cinematic hero, journey enquiry, trust metrics, services, fleet, outstation destinations, Hyderabad local travel, reasons to choose Nanda, owner story, verified review excerpts, booking steps, service area, final call-to-action, contact/map, and footer.
- Use the uploaded owner portrait unchanged in a restrained, premium presentation.

## Content and functionality

- Keep phone, WhatsApp number, address, hours, review figures, destinations, vehicle categories, service links, and map/review URLs in one configuration file.
- Make every call, WhatsApp, booking, navigation, directions, and enquiry action functional.
- Make the journey form create a prefilled WhatsApp message from the visitor’s entered details without inventing specifications or prices.
- Show only supplied reviews, business claims, vehicle categories, and confirmed service areas.

## Visual system

- Establish a charcoal/deep-navy, off-white, and restrained warm-gold design system with editorial display typography, spacious layouts, cinematic photography, subtle transitions, and accessible contrast.
- Generate a cohesive set of original premium travel and vehicle images for the hero and image-led sections.
- Optimize layouts for the current mobile viewport and wide desktop screens, with reduced-motion support.

## Search and quality

- Add the supplied page title and description, social metadata, canonical URL, and LocalBusiness/TravelAgency/TaxiService structured data using only confirmed facts.
- Verify compilation, inspect the full page on mobile and desktop, test the main actions and WhatsApp message creation, and correct visible overflow or interaction errors.

## Technical details

- Implement the page in the existing TanStack Start route and use semantic Tailwind v4 tokens from the global stylesheet.
- Store the uploaded portrait through the project asset flow and import its generated asset pointer.
- Keep section data declarative so services, destinations, fleet categories, and contact details remain easy to update.
